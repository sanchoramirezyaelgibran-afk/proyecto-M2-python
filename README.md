# Proyecto 2: Validación y operaciones

Programa en Python que une dos retos en un menú:
1. **Cuadrantes:** pide coordenadas X y Y (distintas de 0) y dice en qué cuadrante caen.
2. **Longitud de palabra:** valida que la palabra tenga solo letras y cuenta cuántas tiene.

## Cómo ejecutarlo
`python YAEL_SANCHEZ_proyectoM2.py`

## Qué usé
- `while` para repetir la captura hasta que el dato sea válido
- `if / elif / else` para decidir el cuadrante
- Una tupla (nombres de los cuadrantes) y una lista (palabras intentadas)
- `try / except` para que no se rompa si escriben letras en vez de números

## Reflexión
Al principio programar me parecía muy difícil, casi imposible, pero poco a poco
fui avanzando y logré terminar el proyecto.

Con `while` aprendí que el programa puede volver a pedir un dato hasta que sea
correcto, por ejemplo cuando alguien escribe 0 en las coordenadas. Con

números que se escriben.
